# Лабораторна робота №1: Проєктування AI-агента для автоматизації розробки та CI/CD

## 2. Тема, мета та короткий опис лабораторної

### Тема
Проєктування спеціалізованого AI-агента для автоматизації розробки та CI/CD на прикладі C++ Hello World для варіанта 1.

### Мета
Створити спеціалізованого AI-агента, який автоматично генерує кросплатформний Hello World, налаштовує складання, unit-тестування та GitHub Actions для Windows, Linux і macOS.

### Короткий опис лабораторної
Лабораторна робота передбачає проєктування AI-агента, який виконує основні дії з ініціалізації проєкту, створення шаблону застосунку, налаштування системи складання, організації тестування та автоматизації CI/CD. Реалізація спрямована на автоматичне формування базового C++-проєкту з Hello World, який може бути зібраний і перевірений на різних операційних системах.

## 3. Технічні характеристики проєкту

- Мова програмування: C++
- Система складання: CMake
- Тестування: GoogleTest / CTest
- Варіант лабораторної роботи: 1
- Середовище розробки: Visual Studio Code з GitHub Copilot
- Цільова платформа: Windows, Linux, macOS

## 4. Призначення проєкту

Проєкт має забезпечити автоматизоване формування базового C++-проєкту з наступними компонентами:

- кросплатформенний Hello World;
- налаштований CMake для складання проєкту;
- базовий unit-тест BasicAddition;
- конфігурації GitHub Actions для Windows, Linux і macOS;
- структуру AI-агента, який керує цим процесом.

## 5. Agent manifest

Основний манифест агента розташований за шляхом:

- `.github/agents/build-engineer.agent.md`

Цей файл описує роль агента, його відповідальність, інструменти та сценарії взаємодії під час генерації шаблонів проєкту, налаштування збірки та CI/CD-процесів.

## 6. Skills

У проєкті передбачено три основні skills:

1. `project-scaffold`
   - ініціалізація структури проєкту;
   - створення базових каталогів і шаблонів файлів;
   - формування початкової структури Hello World-проєкту.

2. `build-and-test`
   - створення та налаштування CMake;
   - організація збірки проекту;
   - підготовка базового unit-тесту з GoogleTest / CTest.

3. `github-actions`
   - підготовка конфігурацій GitHub Actions;
   - налаштування CI для Windows, Linux і macOS;
   - перевірка автоматизованого запуску збірки та тестів.

## 7. Commands

У проєкті передбачено п'ять команд:

1. `git-init`
   - ініціалізація Git-репозиторію;
   - створення базової структури роботи з проєктом.

2. `create-project`
   - створення шаблону C++ Hello World-проєкту;
   - формування базових файлів застосунку.

3. `create-build`
   - налаштування системи складання через CMake;
   - підготовка конфігурації збірки для різних платформ.

4. `create-actions`
   - створення workflow-файлів GitHub Actions;
   - налаштування запусків для Windows, Linux і macOS.

5. `check`
   - перевірка коректності структури проєкту;
   - валідація збірки та запуск тестів.

## 8. Orchestrator-команда

Передбачена orchestrator-команда `init`, яка послідовно викликає всі п'ять команд у такому порядку:

1. `git-init`
2. `create-project`
3. `create-build`
4. `create-actions`
5. `check`

Команда `init` має зупинятися у разі помилки на будь-якому кроці. Це забезпечує контроль якості процесу ініціалізації проєкту та запобігає подальшим діям за невдалим виконанням попереднього етапу.

> Примітка: `init` є запланованою командою на поточному етапі. Точні інструкції для її запуску будуть уточнені після створення відповідних команд та їхнього підключення до AI-агента.

## 9. Очікуваний результат

Після завершення реалізації проєкту очікується наявність:

- C++ Hello World-програми;
- системи складання на основі CMake;
- unit-тесту `BasicAddition`;
- налаштованих GitHub Actions для Windows, Linux і macOS;
- повної структури AI-агента, який автоматизує створення базового проєкту.

## 10. Гілки гіт-репозиторію

Передбачається використання таких гілок:

- `develop` — основна гілка розробки;
- `feature/ai-agent-hello-world` — робоча гілка з реалізацією функціоналу лабораторної роботи.

## 11. Інструкція запуску AI-агента через GitHub Copilot у VS Code

Для запуску AI-агента через GitHub Copilot у Visual Studio Code необхідно виконати наступні дії:

1. Відкрити папку проєкту в Visual Studio Code.
2. Переконатися, що в редакторі активовано розширення GitHub Copilot.
3. Відкрити вікно чату Copilot у VS Code.
4. Ввести запит на ініціалізацію проєкту або створення шаблону AI-агента.
5. Виконати запит, який відповідає логіці роботи агента: створення проекту, налаштування збірки, тестів і GitHub Actions.
6. Перевірити generated files і коректність результату у відповідних каталогах.
7. Запустити перевірку через відповідну команду або сценарій, якщо вона доступна в поточному етапі реалізації.

> На цьому етапі точні команди запуску `init` і відповідних commands є запланованими та будуть уточнені після реалізації командного інтерфейсу AI-агента.

## 12. Висновок

Цей проєкт орієнтований на створення спеціалізованого AI-агента для автоматизації базових етапів розробки C++-проєкту: від ініціалізації репозиторію до налаштування складання, тестування та CI/CD. За результатом лабораторної роботи має бути отримано автоматизований шаблон Hello World-проєкту з підтримкою Windows, Linux і macOS.
